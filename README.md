# E-Commerce-Sales-Analysis-Dashboard-Power-BI-
Power BI dashboard analysing 2026 e-commerce sales across Bangladesh's 8 divisions. Built a star-schema model with Power Query and DAX to track sales, profit, products, customers, locations and payment methods. Key finding: 613K Taka sales at an 8.44% margin, with Dhaka and Chattogram driving 57% of revenue.
